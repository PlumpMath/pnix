# 16 — 클로저 (커링 + 캡처 재사용)

## 무엇을

람다가 반환한 함수가 바깥 바인딩을 캡처하고, 그 클로저를 **여러 번, 서로
다른 인자로** 재호출해도 캡처한 값이 그대로 유지되는지.

## 실행

```bash
node pnix-cljs/examples/16-closures/pnix_cljs_way.js
```

## 경계

- 이건 **pnix-cljs 제품 런타임**(JS 위 pnix 평가)의 클로저다. JS 함수
  표현식이 자연스럽게 클로저를 갖기 때문에 별도 구현 없이 성립한다.
  `cljs-meta`(자기호스팅 증명 레인) 자신의 클로저는 별개이며 — 이 카탈로그가
  Stage15/N을 승격하지 않듯, 그쪽 세부사항도 여기서 다루지 않는다.
- `06-meta-pair-boundary` 참고: 제품/meta 두 절반의 경계.
